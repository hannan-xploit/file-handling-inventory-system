# 🛒 File Handling Inventory & Shopping System

A Python-based **Inventory and Shopping Cart Management System** built to practice file handling, functions, dictionaries, lists, loops, and menu-driven programming.

The project stores product data in a text file and loads it into a Python dictionary when the program starts.

---

## 🚀 Features

- 📦 Load products from a text file
- 🔍 Search products
- 🛒 Buy products
- ➕ Add new products
- 🗑️ Remove products
- 📊 Update product stock
- 🧾 Show shopping bill
- 💾 Save updated inventory to file
- 🚪 Save & Exit
